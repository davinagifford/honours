A multiple linear regression was conducted to examine the effects of the data source, month, and their interaction on the resulting values.

The overall model was statistically significant, F(3, 112) = 19.32, p < 0.001, explaining approximately 34.1% of the variance in the dependent variable (R² = 0.341, adjusted R² = 0.323).

  • The intercept was statistically significant (β = 0.0824, t = 2.45, p = 0.016).

  • The main effect of data source was not significant (β = 0.0352, t = 0.738, p = 0.462).

  • The main effect of month was also not significant (β = 0.0062, t = 1.45, p = 0.150).

  • However, the interaction between data source and month was statistically significant (β = -0.0214, t = -3.52, p < .001), indicating that the effect of month on value differed depending on the data source.

Residuals were symmetrically distributed with a standard error of 0.0981, ranging from -0.223 to 0.303, suggesting that the model does not under or overfit.

A second regression was conducted to remove the effect of the interaction between data source and month.

This model was also statistically significant, F(2, 113) = 20.68, p < 0.001, explaining approximately 26.8 % variance in the dependent variable (R² = 0.268, adjusted R² = 0.255).

  • The intercept was statistically significant (β = 0.1599, t = 5.980, p < 0.001).

  • The main effect of data source was statistically significant (β = 0.1199, t = -6.277, p < 0.001).

  • The main effect of month was not significant (β = 0.0044, t = -1.403, p = 0.163).

Residuals were symmetrically distributed with a standard error of 0.1029, ranging from -0.211 to 0.280.

To assess whether the interaction between month and the source of data significantly improves the model fit, an analysis of variance (ANOVA) was conducted comparing two nested models:

  • Model 1: included main effects of data_source and month, as well as their interaction (month:data_source).

  • Model 2: included only the main effects of data_source and month.

The comparison revealed that Model 1 provided a significantly better fit to the data than Model 2, F(1, 112) = 12.42, p < .001. This indicates that the effect of month on the outcome variable value differs depending on the data source, and that including the interaction term significantly improves the model’s explanatory power.
